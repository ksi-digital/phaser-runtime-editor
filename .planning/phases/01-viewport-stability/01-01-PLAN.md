**Change 1 — Fixed grid columns (VIEW-03, VIEW-04, VIEW-01):**


This is a single-line CSS string change. 220px matches the hierarchy panel wrapper width; 260px matches the inspector panel wrapper width. The `1fr` center column absorbs remaining space and is immune to side-panel content changes.

**Change 2 — ResizeObserver change guard (VIEW-02):**

Add two private instance fields to the class (after the existing `savedMarginTop` field):
```typescript
private lastObservedWidth = 0;
private lastObservedHeight = 0;
```

Replace the ResizeObserver callback (lines 103-110) with a guarded version:
```typescript
this.resizeObserver = new ResizeObserver((entries) => {
    for (const entry of entries) {
        const { width, height } = entry.contentRect;
        if (width > 0 && height > 0) {
            if (
                Math.abs(width - this.lastObservedWidth) >= 1 ||
                Math.abs(height - this.lastObservedHeight) >= 1
            ) {
                this.lastObservedWidth = width;
                this.lastObservedHeight = height;
                scale.setParentSize(width, height);
            }
        }
    }
});
this.resizeObserver.observe(this.canvasCell);
```

Keep the manual refresh block at lines 114-117 (belt-and-suspenders approach per research recommendation). The guard initializes to 0, so the first observer fire always passes through. The manual block is harmless redundancy that prevents any theoretical race condition.

**Change 3 — Fix destroy margin restoration order:**

In the `destroy()` method, move the margin restoration lines AFTER the `setParentSize()` call. The current code restores margins at lines 144-145 BEFORE `setParentSize()` at line 158. This is wrong because `setParentSize()` triggers Phaser's resize pipeline which recalculates margins when `autoCenter` is active, silently overwriting the restored values.

Correct order in `destroy()`:
1. Disconnect ResizeObserver
2. Remove frame from DOM
3. Move canvas back to original position
4. Restore scale.parent, scale.parentIsWindow, scale.autoCenter
5. Call setParentSize() with original parent dimensions (triggers resize pipeline)
6. THEN restore canvas.style.marginLeft and canvas.style.marginTop (overrides whatever autoCenter computed)

Do NOT add `document.contains()` checks — per user decision, "assume DOM container always exists when deactivate is called."
